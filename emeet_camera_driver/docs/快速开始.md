# 快速开始：环境安装与编译指南

本指南适用于第一次拿到本项目代码的开发人员，帮助你快速搭建开发环境并完成首次编译。

## 1. 系统要求
- **操作系统**: Ubuntu 22.04 LTS (Humble)
- **ROS 2 版本**: Humble Hawksbill

## 2. 环境初始化 (智能脚本)

我们提供了一个智能脚本，它可以自动检测系统缺失的库、创建局部 Python 虚拟环境 (`.venv`) 并安装/矫正所有依赖项（包括 NumPy 2.x 和 OpenCV 等）。

在工作空间根目录下运行：
```bash
cd ~/eMeet_ws
# 执行环境安装脚本 (可能需要输入 sudo 密码以安装系统依赖)
bash src/E7009/robot_arm/emeet_camera_driver/scripts/setup_local_env.sh
```

**该脚本会完成以下工作：**
- 安装 `libudev`, `libhidapi`, `pkg-config` 等系统开发库。
- 自动创建并激活 `.venv` 虚拟环境。
- 确保 NumPy 版本 >= 2.0.0 以避免冲突。
- 安装 `opencv-python-headless` 以确保 UI 兼容性。
- 安装/修复 YOLO 运行所需的 `ultralytics` 与 `torch`（检测到 NVIDIA GPU 时会优先尝试安装 CUDA 版 torch，否则回退 CPU 版）。
- **自动为所有测试脚本和可执行文件添加执行权限 (`chmod +x`)**。

## 3. 项目编译

环境初始化完成后，使用我们的编译脚本进行一键构建。

在工作空间根目录下运行：
```bash
# 执行一键编译脚本
bash src/E7009/robot_arm/emeet_camera_driver/scripts/build.sh
```

**编译成功后：**
- 工作空间下会出现 `build/`, `install/`, `log/` 三个目录。
- 所有的 Python 接口和 C++ 节点均已就绪。
- 每次修改源码后都需要重新运行编译脚本，并重新执行 `source install/setup.bash`，否则终端可能仍加载旧的安装版本。

## 4. 后续步骤

编译完成后，你可以根据需要启动不同的功能模块。具体的运行和测试指令请参考各子包下的 `README.md`：

1. **相机驱动与控制**: [src/E7009/robot_arm/emeet_camera_driver/README.md](../src/E7009/robot_arm/emeet_camera_driver/README.md)
2. **YOLO 2D 检测与追踪**: [src/yolo_ros/README.md](../src/yolo_ros/README.md)

---

### 常见问题
- **找不到 ROS 指令**: 确保你已经安装了 ROS 2 Humble，或者在运行脚本前手动执行了 `source /opt/ros/humble/setup.bash`。
- **install/setup.bash: No such file or directory**: 这说明你还没有编译项目。请先运行 `bash src/E7009/robot_arm/emeet_camera_driver/scripts/build.sh`。
- **NumPy 版本报错**: 我们的脚本已强制要求 NumPy 2.x。如果手动安装了其他版本导致冲突，请重新运行 `setup_local_env.sh` 进行自动修复。
- **YOLO UI 没画面**: 一键启动 `ros2 launch yolo_ros test_yolo.launch.py` 会自动带起相机驱动并发布 `/camera/image_raw`（显示）与 `/camera/image_infer`（推理）；若仍无画面请按 `src/yolo_ros/README.md` 的自检步骤检查 `/camera/image_raw`、`/camera/image_infer`、`/yolo/detections`、`/yolo/tracking`（UI 叠框不依赖 `/yolo/dbg_image`）。
- **YOLO UI 画面卡顿**: 当前 UI 采用“固定刷新率 + 只渲染最新帧 + Qt 矢量叠加”以避免越跑越卡。可用环境变量调参（详见 `src/yolo_ros/README.md`）：\n  - `YOLO_UI_HZ`：UI 刷新频率（默认 30Hz）\n  - `YOLO_UI_USE_OPENGL=1`：可选启用 OpenGL 渲染（缺 OpenGL 会自动回退）
