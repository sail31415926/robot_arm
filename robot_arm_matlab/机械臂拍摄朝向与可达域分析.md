# robot_arm_matlab — 机械臂拍摄朝向 & 可达域分析

本目录是 eMeet 机械臂（6 自由度，末端为相机）在 MATLAB 下的**运动学分析工具集**，
包含两条主线：

1. **拍摄朝向描述规范 v1** —— 把"相机朝哪拍 + 画面水平"统一成 2 自由度的姿态描述；
2. **可达域分析 & 可达性判定器** —— 蒙特卡洛 + 逆运动学(IK) 算出可达空间，
   固化成一个供**上层具身智能体**调用的可达性判定器（MATLAB / CPython / GUI 三种入口）。

统一以 `../robot_arm_description/urdf/eMeetArm_models.urdf` 为模型来源，与仿真/实机一致。

---

## 坐标与姿态约定

- **世界系**：Z 朝上。
- **相机光学系**（遵循 ROS 约定）：`+z` = 光轴（拍摄朝向）、`+x` = 画面右、`+y` = 画面下。
- **拍摄朝向 = 2 自由度**：横滚 roll 钉死为 0（画面始终水平），
  于是姿态只由方位角 `α`(pan) 与俯仰角 `β`(tilt) 决定：
  `光轴 a = [cosβ·cosα, cosβ·sinα, sinβ]`。
- **关节限位**（来自 URDF）：
  J1 ±2.618(±150°)、J2 [-0.8, 3.14]、J3 [-3.14, 0.05]、J4 ±3.1、J5 ±0.7854、J6 [-1.5, 0.5]。

## 文件清单

### A. 拍摄朝向规范 v1
| 文件 | 作用 |
|---|---|
| [shootAxis2R.m](shootAxis2R.m) | **核心底层**：光轴向量 → 相机姿态矩阵 R（roll=0，画面水平）。处理正上/正下万向锁退化。 |
| [shootDir2R.m](shootDir2R.m) | 写法 A（角度）：`(α, β)` → R。做人机接口 / 云台指令，语义同 `GimbalCommand.msg`。 |

| 文件 | 作用 |

## 工作流

```
拍摄朝向规范 v1 (shootDir2R 等)
        │  提供目标姿态 R*（光轴朝前 + 画面水平）
        ▼
eMeetArm_workspace_aim.m  ── GIK 逐点 IK ──► 定姿态可达点云
        │  ① 闭运算补洞(填 IK 漏解针孔)
        │  ② 内收 5cm 安全裕度
        │  ③ 拟合内接椭球护栏
        ▼
eMeetArm_reach_model.mat  (判定器数据)
        │
        ├─► MATLAB:  reachIsReachable / reachProject
        └─► CPython: reach_oracle.ReachOracle  +  GUI
```

**具身智能三层用法**：
① 离线建图（本目录产出栅格）→ ② 在线廉价约束（内接椭球 `(x-c)ᵀA(x-c)≤1`，内部保证可达，可微）
→ ③ 执行前 IK 精确确认。

## 快速开始

### MATLAB 侧
```matlab
% 1) 自检拍摄朝向规范
test_shootDir

% 2) 纯位置可达域
eMeetArm_workspace

% 3) 定姿态可达域 + 生成判定器（覆盖 eMeetArm_reach_model.mat）
model = eMeetArm_workspace_aim;

% 4) 查询
tf = reachIsReachable([0.3 0 0.45], model);   % 是否可达
p  = reachProject([0.3 0 0.45], model);        % 不可达则拉回
```

### CPython 侧（无需 MATLAB）
```bash
pip install numpy scipy            # 判定核心
pip install matplotlib             # 仅 GUI 需要（tkinter 为标准库）

python reach_oracle.py             # 打开 GUI，手动输入 X/Y/Z 判定
python reach_oracle.py --selftest  # 命令行自测
```
```python
from reach_oracle import ReachOracle
ora = ReachOracle()                        # 默认加载同目录 .mat
ora.is_reachable([0.3, 0.0, 0.45])         # -> bool（支持批量 N×3）
ora.project([0.3, 0.0, 0.45])              # 不可达则拉回最近可达点
ora.in_ellipsoid([0.3, 0.0, 0.45])         # 椭球护栏内 = 保证可达
```

## `eMeetArm_workspace_aim.m` 关键参数（脚本开头 §0）

| 参数 | 默认 | 含义 |
|---|---|---|
| `alphaStar_deg` / `betaStar_deg` | 0 / 0 | 拍摄朝向（pan / tilt）；默认水平朝前 `[1,0,0]`。 |
| `tolOri_deg` | 5 | 姿态容差（光轴方向 + 画面水平），单位度。 |
| `posTol` | 0.005 | 位置容差 (m)。 |
| `Nmc` | 40000 | 蒙特卡洛采样数（圈定候选体素）。 |
| `vRes` | 0.05 | 体素/栅格分辨率 (m)。想要更平滑的边界/裕度改 0.025（更慢）。 |
| `nSeeds` | 8 | 每点 IK 最大起点数（越大越少漏解、越慢）。 |
| `closeVox` | 1 | 闭运算补洞半径（体素）；仍多孔调到 2。 |
| `safetyMargin` | 0.05 | 安全裕度：可达域外边界整体内收多少 (m)，即 5cm。 |
| `ellShrink` | 0.98 | 内接椭球安全收缩系数（<1 更保守）。 |

## 注意

- **定姿态可达域比纯位置的小很多**：锁死朝向 + 画面水平后，很多位置到得了却摆不出该姿态。
- **可达域随拍摄朝向变化**：`α*` 是世界系方位，会与 J1(±150°) 耦合，不同方向可达域非对称。
- **判定为栅格级近似**：执行前建议再用 IK 精确确认并取关节解。
- 换朝向/容差/裕度重跑 `eMeetArm_workspace_aim` 后，`.mat` 覆盖更新，MATLAB / Python 侧无需改动，下次加载即最新。
