# robot_arm_matlab — 机械臂拍摄朝向规范

把"相机朝哪拍 + 画面水平"统一成 **2 自由度**的姿态描述，并提供 MATLAB 侧的正反解与自检脚本。

> **可达域分析已移出本目录**（2026-09-11）。原来的 MATLAB 可达域判定器
> （`eMeetArm_workspace*.m` / `eMeetArm_reach_model.mat` / `reachIsReachable.m` /
> `reachProject.m` / `reach_oracle.py`）基于 **V1 云台**的旧 URDF，关节限位已与实机不符
> （文档里写的 J5 ±0.7854、J6 [-1.5, 0.5] 是 V1 云台；换 V2 后是 ±1.5 / ±1.5），
> 栅格 `.mat` 也从未按 2026-07-28 的重标定重算过，已整体删除。
>
> 可达域 / 余量 / 可行性判定现在统一用 **[`robot_arm_api`](../robot_arm_api/README.md)**：
> 纯 numpy、运动学常量从 URDF 现算（换云台或改限位自动跟着变），且给了闭式解而不是栅格近似。
>
> | 原来（MATLAB） | 现在（`robot_arm_api`） |
> | --- | --- |
> | `reachIsReachable(P, model)` 栅格查表 | `check_pose(model, pose)` 闭式 + 数值精解，带人话原因 |

> | 栅格级近似，需执行前 IK 再确认 | 判定本身就是 6 轴整体精解；自碰撞仍由 `/check_state_validity` 兜底 |

## 坐标与姿态约定

- **世界系**：Z 朝上。
- **相机光学系**（遵循 ROS 约定）：`+z` = 光轴（拍摄朝向）、`+x` = 画面右、`+y` = 画面下。
- **拍摄朝向 = 2 自由度**：横滚 roll 钉死为 0（画面始终水平），
  于是姿态只由方位角 `α`(pan) 与俯仰角 `β`(tilt) 决定：
  `光轴 a = [cosβ·cosα, cosβ·sinα, sinβ]`。

与 C++ 侧的对应：`robot_arm_node/include/robot_arm_node/motion/geometry.hpp` 的 `aim_quat`
就是这里的 look-at 写法，`EEF_LEVEL_ROLL` 即"画面水平"那条约束（V2 云台下为 0）。

> ⚠️ 注意 `ArmPose.msg` 的注释（"pitch 正值抬头 / yaw 正值向右"）与 Commander 实际使用的
> `motion::rpy_to_quat`（标准 ZYX）**相反**：代码里 pitch 正 = 俯视、yaw 正 = 向左，没有取反。
> 以代码为准，详见 `robot_arm_api/README.md`。

## 文件清单

| 文件 | 作用 |
|---|---|
| [shootAxis2R.m](shootAxis2R.m) | **核心底层**：光轴向量 → 相机姿态矩阵 R（roll=0，画面水平）。处理正上/正下万向锁退化。 |
| [shootDir2R.m](shootDir2R.m) | 写法 A（角度）：`(α, β)` → R。做人机接口 / 云台指令，语义同 `GimbalCommand.msg`。 |
| [lookAt2R.m](lookAt2R.m) | 写法 B（look-at）：相机位置 + 目标点 → R。做实拍，相机始终对准被摄主体。 |
| [R2shootDir.m](R2shootDir.m) | 反解：R（或光轴向量）→ `(α, β)`。 |
| [test_shootDir.m](test_shootDir.m) | 自检脚本：旋转矩阵合法性 / 画面水平 / 角度往返 / look-at 一致性 / 退化情况。 |

`RTB.mltbx`（Robotics Toolbox for MATLAB，≈26 MB）不进 git，需要时自行下载安装。

## 快速开始

```matlab
test_shootDir                      % 自检：旋转矩阵合法性 / 画面水平 / 往返一致
R = shootDir2R(deg2rad(30), deg2rad(-15));      % 方位 30°、俯仰 -15°
R = lookAt2R([0.3 0 0.45], [1.0 0 0.6]);        % 相机在前者、看向后者
[alpha, beta] = R2shootDir(R);                   % 反解回角度
```

Python 侧不需要这些：`robot_arm_api` 的 `pose_from_look_at(pos, look_at)` 就是 look-at 写法，
与 Commander 的 `aim_quat` 同约定。
